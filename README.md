# 💻 Fundamentos en C++

Repositorio dedicado al aprendizaje, estudio y práctica de la programación en C++, desde los fundamentos del lenguaje hasta el desarrollo de algoritmos, estructuras de datos y métodos de resolución de problemas.

Contiene explicaciones, ejemplos prácticos, ejercicios, implementaciones y soluciones que permiten fortalecer progresivamente las habilidades de programación y pensamiento lógico.

## 🎯 Objetivo

Construir una guía integral de programación en C++, abordando los conceptos fundamentales, las técnicas de programación estructurada, la programación modular, los algoritmos y las principales estructuras de datos.

El propósito es comprender no solamente cómo funciona cada concepto, sino también cómo aplicarlo en la solución de problemas computacionales.

## 🧪 Ejercicios y prácticas

El repositorio incorpora ejercicios de diferentes niveles de dificultad:

- **Intermedio:** funciones, arreglos, matrices, cadenas y sucesiones.

## ▶️ Compilación y ejecución

Para compilar un programa utilizando G++:

```bash
g++ programa.cpp -o programa
```

Para ejecutar en Windows:

```bash
programa.exe
```

También es posible compilar utilizando:

```bash
g++ -std=c++17 programa.cpp -o programa
```
