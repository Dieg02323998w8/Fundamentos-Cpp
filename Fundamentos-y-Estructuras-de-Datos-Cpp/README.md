# Fundamentos y Estructuras de Datos en C++

Colección de ejemplos y ejercicios resueltos para aprender C++ desde cero.
Los programas están separados por tema. Cada archivo `.cpp` es independiente.

## Requisitos
- Un compilador de C++, por ejemplo `g++`.
- Se recomienda C++17.

## Compilar y ejecutar

En Windows (CMD):

```cmd
g++ -std=c++17 01_variables.cpp -o 01_variables.exe
01_variables.exe
```

En Linux:

```bash
g++ -std=c++17 01_variables.cpp -o 01_variables
./01_variables
```

**Importante:** compila un archivo a la vez, porque cada programa tiene su propia función `main()`.

## Contenido

- `01_fundamentos`: variables, entrada/salida y operaciones.
- `02_condicionales`: decisiones con `if` y `else`.
- `03_ciclos`: repeticiones con `for` y `while`.
- `04_funciones`: funciones y parámetros.
- `05_arreglos`: arreglos y matrices.
- `06_cadenas`: trabajo con texto.
- `07_busqueda_ordenamiento`: búsqueda y ordenamiento.
- `08_estructuras`: `struct`, listas, pilas, colas y árboles.
- `09_poo`: clases y objetos.
- `10_archivos`: lectura y escritura de archivos.
- `11_stl`: contenedores de la biblioteca estándar.

## Recomendación de estudio

Primero intenta resolver cada ejercicio por tu cuenta. Después compara tu solución con el código. Cambia los datos de prueba y observa qué sucede.
