# Ejercicios sencillos con solución

Cada ejercicio tiene su código `.cpp` en esta misma carpeta.

1. **Saludo:** pedir el nombre y mostrar un saludo.
2. **Edad:** pedir la edad y mostrarla.
3. **Suma:** leer dos números y mostrar la suma.
4. **Par o impar:** determinar si un número es divisible entre dos.
5. **Mayor de dos:** comparar dos números.
6. **Aprobado o no aprobado:** usar una nota de 0 a 5; se aprueba desde 3.
7. **Tabla:** mostrar la tabla de multiplicar de un número.
8. **Sumatoria:** sumar los números desde 1 hasta N.
9. **Contador:** mostrar los números del 1 al 5 con `while`.
10. **Función sumar:** crear una función que reciba dos números.
11. **Factorial:** calcular el factorial usando un ciclo.
12. **Promedio:** guardar cinco notas en un arreglo y calcular el promedio.
13. **Matrices:** sumar dos matrices de 2 por 2.
14. **Vocales:** contar las vocales de una frase.
15. **Búsqueda:** encontrar un número en un arreglo.
16. **Ordenamiento:** ordenar cinco números con burbuja.
17. **Estructura:** guardar nombre y nota de un estudiante con `struct`.
18. **Lista enlazada:** crear tres nodos y recorrerlos.
19. **Pila:** insertar y retirar elementos con `stack`.
20. **Cola:** insertar y retirar elementos con `queue`.
21. **Clase:** crear una clase sencilla llamada `Persona`.
22. **Archivo:** escribir una frase y leerla.
23. **Vector:** guardar y mostrar tres números con `vector`.

## Para practicar después

- Cambia los números y textos de los ejemplos.
- Agrega una opción para volver a ejecutar el programa.
- Valida que el usuario no ingrese valores fuera del rango.
- Intenta resolver cada enunciado sin mirar el código.
